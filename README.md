# Nexora — متجر الشحن الرقمي

واجهة عربية ومتجر خلفي أولي لمنتجات شحن الألعاب والتواصل الاجتماعي والبطاقات والأرصدة. يتضمن كتالوجًا، سلة، حسابات عملاء، جلسات آمنة مخزنة في SQLite، إدارة طلبات، وإنشاء جلسة دفع Stripe Checkout.

## التشغيل المحلي

يتطلب Node.js 20 أو أحدث.

```bash
cp .env.example .env
npm install
npm start
```

ثم افتح `http://localhost:3000`. في وضع التطوير يستخدم الخادم إعداد جلسة محليًا غير مناسب للإنتاج. إنشاء حساب مدير يتم مرة واحدة عند بدء التشغيل إذا تم ضبط `ADMIN_EMAIL` و`ADMIN_PASSWORD` قبل إنشاء الحساب الأول.

## متغيرات البيئة

انسخ `.env.example` إلى `.env` واضبط القيم. لا ترفع `.env` أو مفاتيح Stripe إلى GitHub.

- `SESSION_SECRET`: سر عشوائي طويل (32 حرفًا على الأقل في الإنتاج).
- `ADMIN_EMAIL` و`ADMIN_PASSWORD`: بيانات المدير الأول؛ كلمة المرور 14 حرفًا على الأقل.
- `STRIPE_SECRET_KEY`: مفتاح Stripe سري من الخادم فقط.
- `STRIPE_WEBHOOK_SECRET`: سر نقطة webhook.
- `BASE_URL`: عنوان HTTPS العام للموقع، دون شرطة أخيرة.
- `STRIPE_PUBLISHABLE_KEY` غير مطلوب: الدفع يبدأ من الخادم ويتحول العميل إلى Stripe Checkout.

## Stripe والإنتاج

اضبط webhook لدى Stripe على `POST /api/webhooks/stripe` للأحداث `checkout.session.completed`, `checkout.session.async_payment_succeeded`, `checkout.session.async_payment_failed`, و`checkout.session.expired`. استخدم Stripe CLI للاختبار محليًا. لا تُعتبر صفحة النجاح إثبات دفع؛ حالة الطلب تتغير فقط بعد webhook صحيح التوقيع وتأكيد `payment_status=paid`.

قبل استقبال العملاء فعليًا: ضع الموقع خلف HTTPS، أنشئ نسخًا احتياطية مشفرة لقاعدة البيانات، اضبط سياسة الخصوصية والشروط والأسعار والعملات ومصدر المنتجات، راجع متطلبات Stripe في بلدك، وأضف مزود fulfillment موثوقًا أو آلية مراجعة يدوية. الكتالوج والأسعار الحالية أمثلة فقط. دفع المنتج لا يشحن تلقائيًا اللعبة أو الحساب؛ لوحة الإدارة تتيح متابعة الطلبات وتحديث تنفيذها.

## حدود هذه النسخة

التسجيل وتسجيل الدخول ينفذان على الخادم بكلمات مرور مخزنة عبر scrypt وجلسات HttpOnly في SQLite. الأسعار يعيد الخادم التحقق منها عند إنشاء الدفع؛ لا تُقبل أسعار من المتصفح. لا نخزن بيانات البطاقات. لوحة الإدارة محمية بدور admin ينشأ من متغيرات البيئة. يلزم إعداد خدمة نشر وصيانة ومراجعة قانونية/تجارية قبل الإنتاج.
